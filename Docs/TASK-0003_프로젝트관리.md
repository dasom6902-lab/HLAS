# TASK-0003 — 프로젝트(Project) 관리 기능

## 상태

구현 완료 / Google Apps Script 실행 테스트 대기

## 구현 내용

- `HLAS-PMS > 프로젝트 관리 > 프로젝트 생성` 하위 메뉴 추가
- HtmlService 기반 프로젝트 생성 대화상자 구현
- 프로젝트명 필수 검증
- `PRJ-0001` 형식의 PROJECT_ID 자동 생성
- 문서 잠금을 사용하여 동시 저장 시 ID 중복 방지
- `01_PROJECT` 시트에 프로젝트 정보 저장
- 상태 기본값 `진행중`, 생성일시와 수정일시 자동 기록
- 프로젝트 생성 후 `09_CHANGELOG` 자동 기록
- 저장 완료 메시지 표시

## 변경 파일

- `Code.gs`
- `UI.gs`
- `ProjectService.gs`
- `Dialog_Project.html`

## 수동 확인 항목

1. 스프레드시트 새로고침 후 프로젝트 관리 하위 메뉴 표시
2. 프로젝트명 미입력 시 저장 차단
3. 첫 프로젝트의 ID가 `PRJ-0001`인지 확인
4. 연속 생성 시 ID가 순차 증가하는지 확인
5. `01_PROJECT` 저장값 확인
6. `09_CHANGELOG` 프로젝트 생성 기록 확인
