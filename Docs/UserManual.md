# HLAS User Manual

## 시작

스프레드시트를 새로고침하면 `HLAS-PMS` 메뉴가 표시된다.

## 주요 메뉴

- 프로젝트/EPIC/FEATURE/FUNCTION/TASK 관리
- KPI Dashboard와 Analytics
- Workflow/Approval
- Notification/Audit
- Import/Export/Backup
- API Manager
- System Health

## 기본 사용법

1. 프로젝트를 생성한다.
2. EPIC → FEATURE → FUNCTION → TASK 순서로 등록한다.
3. Workflow에서 허용된 상태로만 변경한다.
4. 승인 대상은 Approval Center에서 처리한다.
5. KPI Dashboard에서 진행률과 지연 작업을 확인한다.

삭제하려는 항목에 하위 데이터가 있으면 먼저 하위 데이터를 정리해야 한다.
